# Assistente Médico Inteligente com LLM, LangChain e LangGraph

## Sobre o projeto

Projeto desenvolvido como parte do **Tech Challenge – Fase 3 da Pós-Tech FIAP**, com o objetivo de desenvolver um assistente virtual médico utilizando Inteligência Artificial e modelos de linguagem de grande escala (LLMs).

A solução explora técnicas de fine-tuning, integração com LangChain, orquestração de fluxos com LangGraph, consulta a dados estruturados de pacientes fictícios e mecanismos de segurança com validação humana.

O projeto busca demonstrar como essas tecnologias podem ser utilizadas para apoiar o acesso à informação médica, organizar consultas e gerar respostas contextualizadas, mantendo a supervisão humana como parte essencial do processo.

## Tecnologias utilizadas

- Python
- Google Colab
- Qwen 2.5
- Hugging Face Transformers
- PEFT e LoRA
- BitsAndBytes
- MedQuAD
- LangChain
- LangGraph
- SQLite
- Pandas
